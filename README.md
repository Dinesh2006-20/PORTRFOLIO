# Dinesh Kumar R — Animated Portfolio

A responsive, animated portfolio generated directly from the supplied resume.

## Run
No build tools are required.

1. Extract this folder.
2. Open `index.html` in a browser.

For a local server, from this folder run:
- VS Code Live Server, or
- `python -m http.server 5500`
- then open `http://localhost:5500`

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive design and animations
- `script.js` — scroll reveals, cursor glow, mobile navigation

## Source
Content is based on the supplied resume. No new projects, achievements, metrics, or qualifications were added.
